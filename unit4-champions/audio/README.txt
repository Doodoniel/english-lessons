имена будут такие же с другим номером, просто переименуй.

Имена файлов важны: плеер берёт путь из атрибута data-src
(audio/sb/trackNN.mp3) в блоке <div class="card t-teal"> ... id="audios".
Пока файла нет, в плеере пишется «no file yet» — остальное работает.

Формат: mp3. Другое расширение — поменяй data-src в index.html.

Папки audio/wb/ нет: на страницах 16–17 рабочей тетради аудирования нет.

Возможности плеера: play/pause, перемотка кликом по полоске, «⏪ 5s»,
скорость 1× / 0.75×. Кнопки «▶ Track NN» в карточках заданий запускают
тот же плеер.

ВАЖНО про Ex.2 (шесть интервью). Автопроверка стоит, ключ: 1b 2a 3d 4c 5f 6e.
Жёстко заданы грамматикой только 2, 3 и 6 (do athletics; I don't play ice hockey;
we never play tennis together). Для 1, 4 и 5 порядок восстановлен по логике
«I / we» + сочетаемости; в фидбеке прямо написано, что запись важнее ключа.
Как послушаешь трек — при расхождении поправь массив HALVES в index.html.
